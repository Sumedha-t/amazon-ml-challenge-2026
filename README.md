# Amazon ML Challenge 2026

Team project for the Amazon ML Challenge 2026.

## Problem

Business Entity Resolution across multiple independent data sources containing
noisy and inconsistent business information.

## Current Status

Dataset analysis and exploratory data analysis in progress.

## Repository Structure

- `data/` — Local challenge dataset; not committed to Git
- `notebooks/` — Exploratory analysis and experiments
- `src/` — Reusable implementation
- `experiments/` — Experiment tracking and results
- `reports/` — EDA findings, figures and documentation
- `output/` — Generated outputs

## Team Workflow

The modelling approach will be decided after exploratory data analysis.
No final architecture or model has been predetermined.

## Reproducibility

The challenge dataset is not included in this repository.
